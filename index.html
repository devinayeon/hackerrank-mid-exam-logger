FAQ UTS ALPRO

Pertanyaan Penting Seputar Audit Ujian

Syarat kelulusan ujian UTS/UAS Algoritma dan Pemrograman adalah minimal 1 soal diselesaikan secara utuh, yaitu kode lolos seluruh testcase (termasuk hidden testcase) dan meraih poin maksimum pada soal tersebut. Tanpa bukti kelulusan utuh, peserta berstatus PERLU_REVIEW_MANUAL (bukan lulus) atau BELUM_LULUS.

Banyak mahasiswa mencoba trik mencetak teks langsung seperti print("SKIP!") atau print(2) untuk mendapat skor parsial pada sample testcase tanpa memiliki algoritma penyelesaian. Sistem memeriksa konten kode dan perbandingan testcase: jika hanya ada perintah print atau kode sangat pendek (≤ 2 baris), sistem otomatis menandainya dengan flag HANYA_PRINT, KODE_SANGAT_PENDEK, atau SEBAGIAN_TC_LOLOS.

Endpoint HackerRank judge_submissions/ memerlukan hak akses admin atau penguji kontes. Jika halaman kontes dibuka sebagai peserta biasa, HackerRank hanya akan mengembalikan riwayat submission milik akun sendiri. Membuka kontes dengan tab /judge/submissions memastikan seluruh submission mahasiswa dapat ditarik secara massal.

HackerRank menerapkan throttle ketat (sekitar 429 tiap ±4 request cepat). Scraper ini menggunakan arsitektur single worker dengan jeda 1.2 detik antar-request detail kode, serta exponential backoff bertingkat (1.5 dtk, 5 dtk, 15 dtk) khusus saat status HTTP 429 terdeteksi. Setiap kegagalan juga dicatat rapi ke dalam code_errors.

Setelah audit selesai, ekstensi secara otomatis mengunduh 3 berkas yang konsisten:
1. {slug}_submissions_audit.json: Data mentah seluruh mahasiswa, submission terbaik, dan bobot soal.
2. {slug}_rekap_audit.csv: Tabel rekap nilai Excel berisi skor per soal, selisih bobot, flag, dan status kelulusan.
3. {slug}_laporan_audit.html: Dasbor laporan interaktif mandiri (nol request eksternal) dengan daftar mahasiswa, filter status, dan peninjau kode.

PANDUAN PEMAKAIAN

Langkah Penggunaan di Browser

Hanya butuh 3 langkah sederhana di peramban Chrome atau Zen/Firefox.

01

Buka Halaman Kontes Admin

Buka kontes ujian HackerRank Anda (mis. hackerrank.com/contests/[slug]/leaderboard) dan pastikan akun Anda memiliki hak akses penguji/admin.

02

Pilih Mode & Batas Peserta

Buka pop-up ekstensi, pilih mode Submission + audit per peserta, tentukan limit mahasiswa, serta aktifkan opsi Ambil Real Name dan Sertakan Source Kode.

03

Unduh Rekap Otomatis

Klik Download. Ekstensi akan men-scrape data, melakukan audit LULUS_UTUH, dan mengunduh berkas JSON, CSV Rekap, serta Laporan HTML siap pakai.
